# 版控的訓練組態產物

這個資料夾放的是**人在迴圈裡挑出來、無法由程式重新推導**的產物。它們跟
`bundle.py` 的 `CHOSEN_THRESHOLDS` 是同一種東西：由人看結果決定，一旦遺失
就重建不出來。因此**刻意放進版控**，不放 `data/`（`data/` 整個被 .gitignore 擋掉）。

| 檔案 | 狀態 |
|---|---|
| `drop_volatility.txt` | 16 行波動度家族欄位名，人工挑定於 2026-08-16。目前沒有模型在用（m5/m10 已砍），保留供日後復原 |
| `sweep_round4_rf.csv` | Round 4 第一階段 27 組調參結果。**歷史檔案，不再用於訓練** |

## 規定：每個模型各自調參，不得共用組態

每一個選定的模型都必須用自己的特徵集、自己的 label 跑一輪超參數搜尋，
結果寫在 `data/sweep_{key}_rf.csv`（由 `make train` 的階段一自動產生）。
不可以拿別的模型搜出來的組態套過來。

`sweep_round4_rf.csv` 是這條規定確立之前的產物 —— 那時 m1/m2/m6 三個模型共用
同一組參數。它留在這裡只為了保存當時的搜尋結果，不參與現行流程。
