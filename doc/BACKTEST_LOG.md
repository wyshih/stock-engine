# 回測結果記錄

**規則（避免以後又搞混）**：
- 每次測試都用**同一套方法**：`code/backtest/backtest.py` 的 `simulate()`/`performance()`，
  搭配當時的**正式生產模型**（`models/meta_model.pkl` + 13個委員），不額外開
  scratchpad版本、不用不同的臨時Meta模型、不手動硬編門檻——一律讀
  `models/threshold.pkl` 的正式門檻。
- 固定測試區間：`meta_test`（2026-01~今，模型沒看過的資料）。
- 固定參數（除非該次測試就是要調這個參數）：`take_profit=0.20, stop_ma=10`。
- 每次測試前先確認 `models/` 底下是不是最新版（有沒有剛重訓過），跑完立刻記錄
  到這份文件，不要只留在對話裡。

**執行指令**：
```bash
cd code/backtest && python -c "
import sys; sys.path.insert(0,'../models')
from backtest import simulate, performance
trades, price = simulate('meta_test', take_profit=0.20, stop_ma=10)
print(performance(trades, price))
"
```

### 2026-07-26 #4：加入移動停利機制（`simulate()` 新增 `trail_trigger`/`trail_pct`

- 背景：委託研究業界交易條件設計慣例後得知，固定停利會封頂贏家部位的漲幅，

  差距。實作：獲利達 `trail_trigger` 後關閉MA停損，改成追蹤最高收盤價，回落
  超過 `trail_pct` 才出場（`sell_reason="trail_stop"`，`performance()`已加對應
  統計欄位，不算進 `ma_stop_pct`）
- 方法：固定門檻88%/停損MA20（#3驗證過的最佳基礎設定），對
  `trail_trigger∈{0.10,0.15,0.20,0.25} × trail_pct∈{0.05,0.08,0.10,0.15,0.20}`

- **結論：移動停利確實比固定停利有效，驗證了業界「不對稱出場」的說法。
  目前累計改善：0.95%（#2）→ 7.34%（#3）→ 8.99%（#4），約9.5倍。**
- ⚠️ 仍未正式寫回 `backtest.py`/`streamlit_app.py` 的預設值；且交易數持續在

### 2026-07-27 #9：Meta改用排序式label（RF回歸預測「模擬報酬」的當日相對排名），實驗失敗
- 背景：使用者質疑#8報告的「迴歸式label、直接學實際模擬報酬」風險（連續報酬分布
  極度右偏，RF回歸容易被少數極端贏家主導，學不到東西），改成排序式版本——
  訓練目標從「絕對報酬%」換成「當天所有候選裡，實際模擬報酬的相對百分位排名
  （rank_pct，0~1）」，理論上對雜訊更穩健，不用直接學報酬絕對值。使用者要求
  用RF（RandomForestRegressor），不是LightGBM/XGBoost。
- 實作（全部在scratchpad，未進production）：
  1. 寫向量化版模擬器（不是逐筆python迴圈，是對每支股票沿「進場後第k天」整支
     陣列做slice運算），對**每一個**(date, stock_id)候選（不只是門檻通過的訊號）
     都算出「若隔天開盤進場，套用production的MA20兩天確認停損+移動停利
     25%觸發/10%回落規則」會得到的模擬報酬，共產生127.7萬筆候選label
     （橫跨2024-01~2026-07全部~1968支股票）
  2. **正確性驗證**：把這127.7萬筆候選套用門檻0.88篩選+backtest.py同款「持倉中
     不可再進場」去重邏輯後，重現「140筆交易、平均報酬8.992%」，跟production
     的8.99%完全對上（誤差在小數點後第三位），確認向量化模擬器邏輯與
     `backtest.py::simulate()`完全一致，可信賴
  3. 用這127.7萬筆候選算出`rank_pct`(當日排名百分位)當訓練目標，特徵沿用跟
     production Meta一致的13個子模型機率欄位（不額外加特徵，吸取#7教訓），
     訓練`RandomForestRegressor(n_estimators=300, max_depth=6)`
- **結果**：
  - Spearman IC（預測分數 vs 實際模擬報酬）：2025=0.198、2026=0.222——數字上
    看起來是正相關且樣本外沒有衰退，乍看合理
  - 但**用預測分數的百分位門檻篩選（模仿production的門檻機制）**：2025在所有
    門檻（80%~99.9%分位）平均報酬全部是負值或接近零（-0.006~-0.002），2026用
    2025挑出的最佳門檻驗證，1108筆交易、平均報酬僅**0.11%**、勝率35.5%、
    Sharpe 0.194——遠低於#4的8.99%/50.7%/0.764
  - **改用Top-K每日選股**（K=1~10）也一樣失敗：2025在K=1~10全部平均報酬
    在-0.45%~+0.13%之間，沒有一個K能重現接近8.99%的水準
  - **對照診斷**：拿production現有分類模型的`meta_prob`（未經任何改動）跟同一份
    模擬報酬算Spearman IC，結果是**負值**（2025=-0.143、2026=-0.207）——代表
    在全部候選範圍看，meta_prob越高，模擬報酬反而越低；但在極窄的0.88門檻
    （只佔全部候選0.06%）卻能挑出8.99%的好結果。這說明現有#4的有效性是集中
    在一個很窄的機率區間，不是全域單調的關係
- **結論：排序式label一樣失敗，而且失敗方式很一致——不管用百分位門檻還是
  Top-K，只要是「取當天/當期分數最高的一小群」，實際模擬報酬都接近零或負值，
  完全無法重現#4的8.99%。Spearman IC看起來正常（甚至比meta_prob的全域IC還高），
  但IC是被中段大量候選的排序正確性撐起來的，對「最頂端極端贏家」的辨識力
  沒有反映在這個指標上——IC高不代表尾端篩選有效，這是本次新學到的教訓。**
- **額外發現（比失敗結論本身更重要）**：現有分類模型`meta_prob`跟真實模擬報酬
  的全域相關性是負的，8.99%的成功完全靠一個很窄的門檻區間撐起來。這跟先前
  ML專家建議做PBO(Probability of Backtest Overfitting)/Deflated Sharpe Ratio
  檢驗#4是否只是「調參調到運氣好的那組」互相呼應——**這次的結果是支持這個
  疑慮的具體證據，不是反駁**。
- 教訓：
  1. 使用者對「直接回歸絕對報酬」的疑慮是對的，改良成排序式之後問題沒解決，
     說明根本瓶頸不在label的統計性質（絕對值vs排名），而是**現有13個子模型
     機率當特徵，本身就不足以在候選池中穩定辨識「未來會怎麼走」**，換label
     定義治標不治本
  2. Spearman IC/PR-AUC這類「整體排序/分類品質」指標，已經連續兩次
     （這次+meta_prob的負IC對照組）證明跟「頂端門檻篩選出來的實際交易報酬」
     可以完全脫鉤甚至反向，往後任何新方向都必須直接看門檻/Top-K篩選後的
     實際模擬報酬，不能只看整體IC/PR-AUC就下判斷
  3. #4的8.99%高度集中在窄門檻區間、且跟同一份資料算出的模擬報酬全域負相關，
     其穩健性存疑，**建議下一步做PBO/Deflated Sharpe Ratio統計檢定，而不是
     繼續嘗試新的label/模型變體**——如果#4本身就是調參選擇偏誤的產物，
     再多新方向也不會有結果，方向必須先確認再往下走
- 未採用，`train_meta.py`/`build_labels.py`未變動，production設定仍是#4。

### 2026-07-28 #14：PBO(Probability of Backtest Overfitting)檢定，門檻挑選方法論初步過關
- 背景：#9/#10/#12連續發現「在~100~150筆的候選池裡挖規則/調參」容易產生
  樣本外會消失的假訊號，任務#14就是要確認#13(10.05%)這個結果本身，以及
  「用2025調參→2026驗證」這套挑門檻的方法論，是不是也有同樣的過擬合問題。
- 方法（Bailey et al. CSCV簡化版）：把2025~2026(meta_val+meta_test，336個
  交易日)切成S=6個連續區塊，每次取3塊當樣本內(IS)、3塊當樣本外(OOS)，
  共C(6,3)=20種切法(19組有效)。每種切法：在IS用向量化模擬器(已驗證能重現
  真實backtest.py)算真實模擬報酬，挑「平均報酬最高」的門檻(門檻網格
  0.55~0.875)，看這個IS最佳門檻在OOS的表現排名第幾（跟同一組OOS裡其他
  門檻比排名百分位）。PBO = IS最佳門檻在OOS排名落到後半(<0.5)的比例，
  越接近50%代表挑選過程越像純雜訊，越接近0%代表挑選方法本身穩健。
- **結果：PBO = 15.8%**（19組裡16組、84.2%，IS挑出來的最佳門檻在OOS排名
  都落在前10%，只有3組排名墊底，且這3組都同時包含block2跟block4這兩個
  特定區塊——可能是這兩段期間本身走勢比較極端/特殊，不是普遍現象）。
  這是相對健康、偏低的PBO值，代表「2025調參→2026驗證」這套門檻挑選方法
  本身不是系統性地在雜訊裡挑巧合。
- **結論：#13的門檻挑選方法論初步過關，不代表10.05%這個具體數字本身沒有
  雜訊（樣本仍只有89筆），但至少排除了「整個方法論從根本上就是在自欺欺人」
  這個最壞的疑慮。任務#14的PBO部分先告一段落，Deflated Sharpe Ratio
  還沒做，使用者要求先記錄、晚上再重跑（可能是重跑PBO看穩定性、或補做
  DSR、或用更長歷史區間重新切block，待續，不是今天判定為完成）。**
- 程式碼位置（scratchpad，未進production，如需重跑要重建）：
  `vectorized_sim.py`（已驗證的向量化模擬器）、`pbo_test.py`（CSCV PBO
  流程）、`pbo_data.parquet`（meta_val+meta_test合併後的候選+機率+block

### 結論

**1. 改成無去重後，結論**有**改變 —— 2024 從「小賺」變成「全面小賠」，六格翻負。**

平均報酬由正翻負的六格（#24 → #25）：
R1/RF/2024（+3.51% → **−1.13%**）、R2/RF/2024（+1.00% → **−1.58%**）、
R2/MLP/2024（+0.56% → **−2.64%**）、R2/LSTM/2024（+0.51% → **−1.12%**）、
R1/MLP/2026H1（+0.96% → **−2.57%**）、R1/LSTM/2026H1（+2.81% → **−6.95%**，n 從 18 → 40）。
沒有任何一格由負翻正（R1/LSTM/2024 兩種口徑都是負的，−1.89% → −3.92%）。
方向很一致：**2024 全部往下、2025 全部往上**（例：R1/RF/2025 +4.41% → +12.61%，
R2/RF/2025 +5.53% → +10.56%）。原因是去重規則把「同一支連續多天達標」壓成一筆，
而連續達標最常發生在已經起漲的股票上：在 2025 大多頭這些重複訊號是賺的、
被去重砍掉所以 #24 低估；在 2024 震盪年這些重複訊號是賠的（連續達標卻不漲＝
追高被套），被去重砍掉所以 #24 高估。**#24 的「18 格有 14 格打贏零技能」在
無去重口徑下不成立。**

**2. 扣掉 matched-N 之後，真的贏的格子：18 格中 15 格 Δ平均為正，但只有 8 格
   幅度像是「訊號本身有料」。**

- **明顯贏（Δ平均 ≥ +3pp 且 Δ勝率 ≥ +9pp）：6 格** ——
  R1/RF/2026H1（+3.72pp / +12.2pp）、R1/MLP/2024（+3.49pp / +11.1pp）、
  R1/MLP/2025（+5.77pp / +9.7pp）、R2/RF/2026H1（+3.56pp / +9.1pp）、
  R2/MLP/2026H1（+3.69pp / +9.5pp）、R1/LSTM/2025（+3.08pp / +6.0pp，勝率差略小）。
- **小贏但不足以下結論（Δ平均 +0.15 ~ +2.31pp、Δ勝率 +1.2 ~ +4.7pp）：9 格** ——
  三個家族的 2024 全部落在這裡（+0.15 ~ +1.36pp），以及 RF/MLP/LSTM 的 2025
  （+1.30 ~ +2.21pp，只有 R1/MLP 例外）。這種幅度在 6 萬筆高度相關的交易上
  不算穩健證據。
- **輸給 matched-N：3 格** —— R1/MLP/2026H1（−7.89pp）、R1/LSTM/2026H1
  （−23.93pp，n=40 純雜訊）、R2/MLP/2024（−0.18pp，實質平手）。
- **最重要的一個發現：優勢主要來自「哪幾天出手」，不是「挑哪一支」。**
  2025 的 fixed30 平均報酬只有 +2.79%，但同期 matched-N 高達 +8.65 ~ +13.32%
  —— 只是把出手日期分布複製成跟模型一樣，什麼股票都不挑，就吃掉了大部分報酬。
  模型再往上多出來的只有 +1.3 ~ +5.8pp。**#24 用 fixed30 當唯一對照會把

- 2024 三個家族全部是負的絕對報酬，且 matched-N 也是負的：那一年這套

## 2026-08-16 #27：②(抄底型) vs ⑤(動能型) 的分歧分析 —— **兩模型一致同意時最可靠，分歧處是雜訊；② 獨有的部分甚至輸給全買**
